# 모바일 교환권 연동

현재 포인트는 기기 안의 가상 비콘 체험 기록입니다. 웹과 앱 상점에는 편의점·치킨·아이스크림 기프티콘 예시가 표시되고, 하슬랑 꾸미기 아이템은 체험 포인트로 교환할 수 있습니다.

실제 쿠폰을 발급하려면 운영 주체가 발송 업체와 상품 및 비용 한도를 정합니다. 예를 들어 기프티쇼 비즈는 [쿠폰 발송 API 가입과 비즈머니 선충전](https://biz.giftishow.com/faqview?faqSeq=144)이 필요합니다. [카카오 선물하기 for Biz](https://kakaobusiness.gitbook.io/main/tool/for-biz/tools/api)는 그룹 마스터가 인증키를 발급하고 모바일 교환권 템플릿을 설정할 수 있습니다.

실제 교환은 운영 서버가 검증한 적립 기록을 사용합니다. 서버는 교환 요청마다 중복 처리 방지 키를 두고, 잔액과 예산을 예약한 뒤 발송 결과를 확인해 차감합니다. 발송 상태가 불명확하면 업체 주문 결과를 조회한 후 확정하고, 실패하면 예약을 해제합니다. 발송 업체 인증키는 운영 서버에 보관합니다. 앱의 가상 체험 기록은 실물 상품권 잔액으로 이전하지 않습니다.
