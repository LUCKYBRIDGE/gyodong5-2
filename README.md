# 신호등 알리미

강릉시 시민제안 제출용 시제품입니다. 정식 출시 앱이 아닙니다.

안드로이드에서 다른 앱을 보는 중에 횡단보도 경고를 표시하는 가상 비콘 체험입니다. 앱 이름과 사이렌 디자인은 5난초 학생들이 학급 투표로 골랐습니다.

## 체험 방법

1. Android 8.0 이상 휴대폰에 APK를 설치하고 앱을 엽니다.
2. **다른 앱 위에 표시 허용**을 눌러 안드로이드 설정에서 ‘신호등 알리미’ 권한을 켭니다.
3. 앱으로 돌아와 **가상 접근 시작**을 누른 뒤 7초 안에 홈 화면으로 나가 다른 앱을 엽니다.
4. 앱 화면을 가리는 경고창에 **횡단보도 앞입니다. 주변을 봐주세요.**가 표시됩니다. 가상 비콘에 접근한 뒤 경고창을 닫지 않거나 화면을 끈 상태로 10초가 지나면 10점이 쌓입니다. 화면을 쓰는 동안에는 적립창이 약 3초간 표시됩니다.
5. 앱에서 오늘 적립 횟수와 누적 점수를 확인합니다. 기기 날짜 기준으로 하루 최대 3회 적립할 수 있습니다. 한도에 도달한 뒤에도 경고창은 표시됩니다.

경고창을 직접 닫으면 짧은 안내와 함께 적립을 취소합니다. 가상 비콘에서 멀어져도 시작된 경고와 적립은 10초까지 계속됩니다. Android 가상 체험 서비스는 시작 35초 뒤 종료됩니다. 화면이 꺼진 동안에는 화면을 켜지 않고 기록합니다. 잠금 화면, 시스템의 일부 영역, 오버레이를 숨기는 앱에서는 표시가 제한됩니다.

## 실제 비콘

현재 APK는 시연용 가상 감지기를 사용합니다. 실제 비콘은 [BLE 감지 설계](docs/ble.md)의 방식으로 `BeaconSource`에 연결할 수 있습니다.

## 앱 화면과 디자인 교체

- 홈은 사용 가능 잔액, 누적 적립 점수, 오늘 적립 횟수를 보여줍니다.
- 포인트 상점에서는 가상 아이템을 각각 한 번 교환할 수 있습니다. 교환한 점수는 잔액에서 차감됩니다. 칭호는 체험으로 모은 누적 적립 점수를 기준으로 열립니다.
- 모바일 교환권은 편의점·치킨·아이스크림 기프티콘을 상품 예시로 표시합니다. 실물 교환권 발급은 [운영 연동](docs/coupons.md)이 필요합니다.
- 하슬랑 아바타는 알림 체험을 1회·3회·7회 완료하면 칭호와 함께 성장합니다. 상점에서 교환한 아이템은 하슬랑 화면에서 착용하거나 벗길 수 있습니다.
- 안내 화면은 횡단보도 대기 구역에 비콘을 설치한 뒤 휴대폰이 감지하는 흐름과 현재 가상 체험 방법을 보여줍니다.
- 앱 이름과 색은 [브랜드 리소스](src/main/res/values/brand.xml)에 있고, [둥근 사각형 사이렌 아이콘](src/main/res/drawable-nodpi/ic_signal_alert.png)는 앱 화면과 디자인 소개에서 사용합니다. 홈 화면에는 기기의 아이콘 모양에 맞춰 채워지는 [별도 런처 리소스](src/main/res/mipmap-anydpi-v26/ic_launcher.xml)를 사용합니다.
- [캡처 폴더](captures/)에서 버전별 실기기 화면을 확인할 수 있습니다.

## 빌드와 테스트

JDK 17 이상과 Android SDK 36, Build Tools 35.0.0이 필요합니다. SDK는 `ANDROID_HOME` 또는 Android Studio의 `local.properties`로 지정합니다.

```sh
./gradlew assembleDebug
./scripts/test.sh
```

빌드 결과는 `build/outputs/apk/debug/Traffic-debug.apk` 또는 Gradle이 지정한 동일 디렉터리의 debug APK입니다.

## 웹 체험

웹은 `web/` 폴더에서 제공됩니다. 로컬에서는 `python3 -m http.server 4173 --directory web`으로 실행합니다. 브라우저에서 가상 비콘, 화면 꺼짐 상황, 경고 유지와 닫기, 포인트와 하슬랑 성장을 체험할 수 있습니다. 웹 체험 기록은 브라우저에 저장됩니다. 웹의 화면 끄기는 시뮬레이션입니다.

웹 APK 다운로드는 `web/downloads/traffic-demo.apk`를 사용합니다. 안드로이드 앱을 업데이트할 때 빌드한 APK를 이 경로에도 복사합니다. 웹 적립 규칙은 `node --test web-tests/rewards.test.mjs`로 검사합니다. GitHub Pages 워크플로는 `web/` 폴더만 공개합니다.

Android 0.4.2 이하에서 최신 버전으로 바꾸려면 앱 서명이 달라 기존 앱을 삭제한 뒤 설치해야 합니다. 앱을 삭제하면 기기에 저장한 포인트와 체험 기록도 삭제됩니다.
